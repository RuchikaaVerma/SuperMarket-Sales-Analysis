## 📌 1. Problem Statement

Analyze supermarket sales data and find useful information about **products,
branches, categories, customers, payments, and ratings** — then turn those
findings into concrete business decisions.

> ✅ This repo contains **working code**, not just a write-up: every number
> and chart in `report/Supermarket_Sales_Analysis_Report.pdf` is produced by
> actually running the scripts/notebook in this project against
> `data/supermarket_sales.csv`.
