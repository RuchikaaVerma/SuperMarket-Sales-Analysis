## 📌 1. Problem Statement

Analyze supermarket sales data and find useful information about **products,
branches, categories, customers, payments, and ratings** — then turn those
findings into concrete business decisions.

> ✅ This repo contains **working code**, not just a write-up: every number
> and chart in `report/Supermarket_Sales_Analysis_Report.pdf` is produced by
> actually running the scripts/notebook in this project against
> `data/supermarket_sales.csv`.

## 📊 3. Dataset

`data/supermarket_sales.csv` — 500 transactions with these columns:

| Column          | Description                                |
|-----------------|---------------------------------------------|
| `InvoiceID`     | Unique transaction ID                       |
| `Date`          | Date of the transaction                     |
| `Branch`        | Branch code (A, B, C)                       |
| `City`          | City of the branch (Kanpur, Delhi, Mumbai)  |
| `Category`      | Product category                            |
| `Product`       | Product name                                |
| `Unit Price`    | Price per unit (Rs.)                        |
| `Quantity`      | Units purchased                             |
| `CustomerType`  | Member / Normal                             |
| `PaymentMethod` | UPI / Cash / Card                           |
| `Rating`        | Customer rating (1–5)                       |
| `Sales`         | Quantity × Unit Price                       |

> ⚠️ **Note:** No raw POS export was supplied for this project, so
> `src/generate_data.py` simulates a realistic 500-row dataset (with a few
> intentionally messy rows, so the cleaning step has something to do). If
> you have your own real supermarket sales CSV, just replace
> `data/supermarket_sales.csv` with it (keeping the same column names) and
> re-run the pipeline in Section 4 — everything downstream (cleaning,
> analysis, charts, and the PDF report) will recompute automatically from
> your real numbers.

## ▶️ 4. How to Run This Project

### Step 1 — Set up the environment

```bash
# (recommended) create a virtual environment
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# install dependencies
pip install -r requirements.txt
```

### Step 2 — (Optional) Regenerate the raw dataset

Only needed if you want a fresh simulated dataset, or don't have
`data/supermarket_sales.csv` yet:

```bash
python src/generate_data.py
```

### Step 3 — Run the full analysis

Cleans the data, answers all 6 questions, saves charts:

```bash
python src/main.py
```

This prints the answers to the terminal and writes:
- `outputs/charts/*.png` (6 charts)
- `outputs/summary.json` (all computed results)

### Step 4 — Rebuild the Jupyter notebook *(optional — a pre-executed copy is already included)*

```bash
python src/build_notebook.py
jupyter nbconvert --to notebook --execute --inplace notebooks/Supermarket_Sales_Analysis.ipynb
```

Or just open `notebooks/Supermarket_Sales_Analysis.ipynb` directly in
Jupyter/VS Code — it already contains its executed outputs and charts.

### Step 5 — Rebuild the final PDF report

```bash
python src/build_report.py
```

This reads `outputs/summary.json` and `outputs/charts/`, and regenerates
`report/Supermarket_Sales_Analysis_Report.pdf`.

### 🚀 Run everything in one go

```bash
python src/generate_data.py && \
python src/main.py && \
python src/build_notebook.py && \
jupyter nbconvert --to notebook --execute --inplace notebooks/Supermarket_Sales_Analysis.ipynb && \
python src/build_report.py
```

## ❓ 5. Business Questions Answered

| # | Question |
